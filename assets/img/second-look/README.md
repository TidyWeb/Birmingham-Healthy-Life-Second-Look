These twelve figures were drawn with matplotlib by `tools/ethics_register.py`. On 20 October 2026 they were replaced on the site by live, read-only Signal Box boards, drawn from the same data by `tools/signal_box.py`. The live boards are sharper, readable by screen readers, and can't disagree with each other; some of these drawings were cramped or malformed. No page uses them now. They're kept to show the earlier version.
